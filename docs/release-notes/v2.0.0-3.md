# ezSsh v2.0.0-3

Fix release for the native build. Pre-release: only copies set to the **pre-release** update channel are offered it. Coming from ezTerm? Read the notes of [v2.0.0-1](https://github.com/the-angwe/ezssh/releases/tag/v2.0.0-1) first: the database upgrade is one way.

## Fixed

- **macOS: ⌘ shortcuts did nothing.** ezSsh turns off eframe's Ctrl+C / Ctrl+V / Ctrl+X handling so a terminal gets those keys (^C interrupts, ^V is quoted-insert), and on a Mac that switch also removed ⌘C / ⌘V / ⌘X. They are back, and the standard chords are in place:
  - Terminal: ⌘C copy, ⌘V paste, ⌘A select all, ⌘F find, ⌘+ / ⌘− / ⌘0 font size. The context menu shows them.
  - Window: ⌘W close tab, ⌘N new session, ⌘, settings, ⌘M minimise, ⇧⌘[ / ⇧⌘] and ⌥⌘← / ⌥⌘→ previous / next tab, ⌘1…⌘9 pick a tab (⌘9 the last). ⌘B (sidebar), ⌘K (session filter) and ⇧⌘W (view mode) now work while a terminal has the keyboard too; no shell sees a ⌘ chord.
  - ⌘Q asks before quitting with live sessions (if that setting is on) instead of ending the process on the spot.
- **Linux and Windows: Ctrl+C / Ctrl+X / Ctrl+V in text fields** (session dialog, credentials, the session filter, the find bar) did nothing, for the same reason. They work while no terminal has the keyboard; a focused terminal still gets the keys.
