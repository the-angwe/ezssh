# ezSsh v2.0.0-beta0

**The first native build.** ezSsh is a permanent fork of ezTerm, rebuilt as one Rust program: an egui window around an alacritty_terminal terminal, with no webview, no Next.js and no xterm.js. Sessions, folders, credentials, known hosts, settings, backups and sync bundles from ezTerm keep working.

This is a pre-release: only copies set to the **pre-release** update channel are offered it.

## Coming from ezTerm

- ezSsh opens ezTerm's database (`ezterm.sqlite` in ezTerm's data folder) and unlocks with the same master password. Quit ezTerm before starting ezSsh.
- **The switch is one way.** On its first start ezSsh upgrades the database (session-owned passwords, below), and ezTerm refuses to open a database with a migration it does not know. To keep the option of going back, make a backup in ezTerm first (or copy `ezterm.sqlite`), or try ezSsh on a copy with `ezssh --db <copy>`.
- It installs next to ezTerm, not over it (new identifier `xyz.angwe.ezssh`, binary `ezssh`). ezTerm's uninstaller removes only its own files and the per-user VcXsrv, not the database, so it can be uninstalled at any time.
- ezTerm does not update into ezSsh (it checks upstream's releases with upstream's key). Install ezSsh once by hand; from then on it updates itself.
- A session's password now belongs to that session. Sessions that shared one stored password each get their own copy on first start; the Credentials manager lists only private keys and key passphrases.

## What changed

### One native process

- Terminal output goes straight from the SSH or shell reader into the terminal model. The webview's buffering, arm / detach handshake and stall watchdog are gone, along with the bugs they worked around.
- Software rendering (WARP on Windows) is picked automatically on machines without a usable GPU, so VMs and RDP sessions work; `--renderer warp|glow` forces a renderer.
- Linux packages no longer need webkit2gtk: xkbcommon, fontconfig, X11 / Wayland client libraries and Vulkan or EGL.
- No splash window: the main window opens directly.

### Terminal

- Kitty keyboard protocol (Claude Code, neovim), mouse reporting for tmux / vim / htop, OSC 8 hyperlinks next to plain URLs.
- Nerd Font symbols are bundled; CJK and emoji come from the system fonts.
- Appearance… in the terminal and tab-header menus: tab colour, font, size, scrollback and cursor, previewed live, applied to the tab or saved to the session.

### File pane

- Drop files and whole folders from the file manager to upload them; download files, several files or whole folders.
- Delete several selected items at once.
- Cancel a running or queued transfer; partial files are removed.

### Updates and packaging

- Windows: per-user NSIS setup and an MSI, both with VcXsrv. Linux: AppImage and deb for x86_64 and aarch64. macOS: `.app` (unsigned). Portable `.tar.xz` archives for every platform.
- The updater checks `latest.json`, verifies each installer's minisign signature while downloading and requires the signed version to match, then installs it the way it was installed (NSIS, MSI, AppImage, deb, `.app`) and restarts. Portable copies link to the release instead.

## Known limitations

- Wayland: no file drops into the pane (winit); use the pane's Upload menu, or run under XWayland.
- Dragging files out of the pane to the desktop is not supported.
- The Windows executable has no embedded icon yet; the macOS app is not signed or notarised.
