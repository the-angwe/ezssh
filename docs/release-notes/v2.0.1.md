# ezSsh v2.0.1

The first stable release of ezSsh 2: every copy, on either update channel, is offered it. Coming from ezTerm? Read the notes of [v2.0.0-1](https://github.com/the-angwe/ezssh/releases/tag/v2.0.0-1) first: the database upgrade is one way.

## Changed

- **A private key and its passphrase are one credential.** Adding a key (in the session dialog, the *Fix authentication* overlay or the credentials manager) now asks for the key and its optional passphrase together; there is no separate passphrase to pick per session any more. In the credentials manager each key shows whether a passphrase is saved, and offers *Replace key* (the new key comes with its own passphrase, or none) and *Change passphrase* (set, change or remove it). In *Fix authentication*, a passphrase typed under a picked key replaces the one saved with that key. A key's passphrase applies to every session that uses the key.
- **Existing passphrases move onto their keys.** On first start the database is upgraded: each key takes the passphrase its sessions paired it with (if two sessions paired the same key with different passphrases, the oldest session's wins). A passphrase that no key took stays in the credentials manager under *Unattached key passphrases*, where it can be deleted. Backups now carry a key's passphrase with the key, and restoring an older backup joins them the same way.
- **One-way upgrade:** after it, ezSsh 2.0.0-6 and earlier can no longer open the database.

## Fixed

- **Save / Cancel of a new private key sit inside its form.** In the session dialog the *New private key* form drew its buttons below the panel, across its bottom edge.
