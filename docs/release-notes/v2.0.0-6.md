# ezSsh v2.0.0-6

Pre-release: only copies set to the **pre-release** update channel are offered it. Coming from ezTerm? Read the notes of [v2.0.0-1](https://github.com/the-angwe/ezssh/releases/tag/v2.0.0-1) first: the database upgrade is one way.

## New

- **A paste that ends in a line break asks first.** With Settings → Terminal → *Warn before pasting multiple lines* on (the default), a single line copied with its line break (`rm -rf build⏎`) now opens a *Paste and run?* dialog, because the shell would run it the moment it lands. Several lines still ask *Paste multiple lines?*; a line without a line break pastes straight in.

## Fixed

- **A taken forward port says who holds it.** When a local or dynamic forward cannot start because its port is in use, the message now names the tab whose forward has it (`127.0.0.1:8000 is in use by the forward of tab "dn"`), or says another program or ezSsh window holds it. Before, it read like a forward left behind by a dropped connection; usually two sessions were set to start the same port and the first tab to connect took it.
- **The forward dialog names its session**: `Forward for "dn" (session config)` when it saves to the session, `(this tab)` when it is for the open tab only.
