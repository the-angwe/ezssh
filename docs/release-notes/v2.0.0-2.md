# ezSsh v2.0.0-2

Fix release for the native build. Pre-release: only copies set to the **pre-release** update channel are offered it. Coming from ezTerm? Read the notes of [v2.0.0-1](https://github.com/the-angwe/ezssh/releases/tag/v2.0.0-1) first: the database upgrade is one way.

## Fixed

- **Ctrl+L in local shell tabs** cleared nothing; it only reprinted the prompt. The shell was started with the environment ezSsh itself had, and a desktop launcher gives it no `TERM` (a terminal launching ezSsh gives it that terminal's). Readline and ZLE then had no `clear` capability. Local shells now get `TERM=xterm-256color` and `COLORTERM=truecolor`, the terminal type SSH sessions already requested, so Ctrl+L, `clear`, colours and cursor keys behave the same in both.
