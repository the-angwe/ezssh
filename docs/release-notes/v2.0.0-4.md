# ezSsh v2.0.0-4

Pre-release: only copies set to the **pre-release** update channel are offered it. Coming from ezTerm? Read the notes of [v2.0.0-1](https://github.com/the-angwe/ezssh/releases/tag/v2.0.0-1) first: the database upgrade is one way.

## New

- **The sessions sidebar no longer has to hide when a tab opens.** Settings → Sessions → *Hide the sessions sidebar when a tab opens* (on by default, as before). Turned off, opening a tab leaves the sidebar as it was.

## Verify

```bash
sha256sum -c SHA256SUMS
```
