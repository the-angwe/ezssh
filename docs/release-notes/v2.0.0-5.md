# ezSsh v2.0.0-5

Pre-release: only copies set to the **pre-release** update channel are offered it. Coming from ezTerm? Read the notes of [v2.0.0-1](https://github.com/the-angwe/ezssh/releases/tag/v2.0.0-1) first: the database upgrade is one way.

## New

- **Linux and Windows: Alt+1…Alt+9 pick a tab** (Alt+9 the last one), like ⌘1…⌘9 on macOS. They work while a terminal has the keyboard too, as in GNOME Terminal and Konsole, so programs in the terminal no longer see Alt+digit (readline's repeat count, irssi / weechat window switching). AltGr chords still type their characters (`{ [ ]` on German layouts); on AZERTY the unshifted digit row works.
  - Known limitation on Windows: Alt codes typed on the numpad (Alt+0169) switch tabs as well.
- **The sessions sidebar no longer has to hide when a tab opens.** Settings → Sessions → *Hide the sessions sidebar when a tab opens* (on by default, as before). Turned off, opening a tab leaves the sidebar as it was.

## Fixed

- **Tab order in dialogs follows the layout.** Tab now goes through a dialog's fields top to bottom, then its buttons left to right (Cancel before the main action), and reaches the ✕ last. Before, the ✕ came first and the buttons ran right to left. Tab also stays inside an open dialog instead of jumping to the notifications, and a number field is one stop: ↑ / ↓ step its value (Shift: by 10), the ▲ ▼ buttons are for the mouse.
